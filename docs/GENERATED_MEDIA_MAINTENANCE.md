# 本地媒体维护

OSS启用后，现有任务维护循环每5分钟启动一个后台补传批次，最多20个URL。重复tick复用在途批次；上传使用线程，既有调度、取消、对账继续运行。即时上传和补传共享每URL互斥，失败后保本地并在后续轮转中重试。

扫描保持原范围：科普成片、模板预览、已发布作品、漫剧资产/分镜媒体及原资产params媒体键；不把科普分镜中间图、音轨、视频扩大到自动OSS扫描。稳定游标会继续向后扫描，缺文件或失败记录不阻塞后续媒体。任何补传结果都不删除本地副本，FFmpeg及历史引用继续可用。

手动审阅仍可在backend目录运行 `python -m scripts.backfill_oss_media --dry-run --limit 20`；关闭OSS时自动维护与手动补传均不扫描数据库。
