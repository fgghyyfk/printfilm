# 三队列任务调度与独立生成

任务持久化在 `task_runs`，按 `queue_type` 分为 `text`、`image`、`video`。剧本、分镜规划与配音归文字队列；图片生成归图片队列；视频生成与合成归视频队列。科普流水线按当前 phase 分流。音频是前台独立分类，后台共享文字队列。

各队列的全站并发分别由以下环境变量控制：

```dotenv
TASK_QUEUE_TEXT_CONCURRENCY=4
TASK_QUEUE_IMAGE_CONCURRENCY=4
TASK_QUEUE_VIDEO_CONCURRENCY=4
```

未配置时，各队列沿用 `TASK_RUNTIME_MAX_CONCURRENCY`，默认每队列 4，总容量 12。单用户限制按队列计算，团队限制仍跨队列共用。视频等待上游的 `awaiting_poll` 任务占视频队列容量，但不占本地执行协程。

调度器使用 PostgreSQL 每队列事务级 advisory lock、任务行锁与状态条件更新领取任务。持有执行任务的进程每 10 秒续租；其他进程只恢复已经过期的租约。取消使用独立槽位。仍以内联方式响应的聊天请求保留原请求行为，并记录所属队列。

## 生成与任务记录

- 主侧栏提供「视频」「图片」「我的任务」入口，桌面与移动菜单共用配置；视频、图片与 AI 短视频项目分别高亮。
- `/tools/video`、`/tools/image`、`/tools/audio`：复用已有接口的独立生成工作台；原 `/tools/t2i`、`/tools/t2v` 等工具地址保留原工具表单。
- `/tasks`：「我的任务」统一展示工具工作台、漫剧、短视频及画布的生成任务，默认显示全部，支持视频、图片、音频、文字分类，以及状态、本地/上游任务 ID、日期筛选和下载。以上生成与任务页面需要登录，登录后返回原地址并保留查询参数。
- `GET /api/tasks/generations` 从 `TaskRun` 读取各入口任务，并合并没有关联统一任务的旧 `ToolRun`，关联记录只显示一次；服务端完成筛选、统计和分页，读取列表不会补写任务或调用上游。`GET /api/tasks/generations/{task_id}` 返回统一任务详情；旧工具记录仍使用工具详情接口。个人和团队空间分别授权，切换空间时取消旧请求并清空详情。
- 生成请求受理后先提交任务登记，再执行外部生成；个人配音、试听和分集合成也登记任务，保留各自原计费规则。完成、失败或取消均持久化状态，已保存的结果快照用于预览或下载，文字生成可查看及下载文本。
- HTTP 内联生成使用独立续租心跳保护长请求，调度器不会把仍在生成的任务误判为中断后重排队。进程中断且租约过期时，任务收敛为失败或取消并完成原有结算，不自动重发生成请求。
- 生成与任务页统一使用主站的白色、石墨灰和荧光绿配色，只保留主侧栏。「最近生成」和任务列表统一使用全局 `AssetDetailDialog`，复用媒体预览、放大、复制说明和下载，不再保留独立生成详情组件或样式。多结果可切换，进行中的详情独立刷新，任务离开当前筛选列表后仍能更新结果。
- 视频工作台支持「文生视频」「首尾帧」「全能参考」。文生视频直接提交文字，不再为新模式额外生成/计费首帧；首尾帧要求一张首帧、尾帧可选；全能参考按模型目录限制接收图片、视频和音频，总数不超过 12 份。各模式分别保留已选资料。
- 参考资料支持本地上传和资产库多选。`GET /api/tools/reference-assets` 按媒体类型、名称服务端筛选分页，仅返回当前用户个人项目中有媒体的资产；提交只接受上传索引或资产 ID，由服务端校验权限、媒体类型和数量，不接受客户端任意 URL。文件上限 40MB，图片支持 JPG/PNG/WebP，视频支持 MP4/MOV/WebM，音频支持 MP3/WAV/M4A/AAC/OGG/FLAC。
- `POST /api/tools/estimate` 在提交前只读计算预计消耗，不创建任务或冻结余额；与正式任务共用模型策略、计费维度和估价规则。前端随模式、模型、画幅、分辨率、时长和资料更新报价，旧报价不得用于新参数提交；提交携带报价版本，价格变化返回 409 后须重新确认。未启用计费时明确显示本次不扣费；缺价或报价失败不能作为免费提交。
- `POST /api/tools/run`：先创建 `ToolRun` 和同一条用于执行、计费的 `TaskRun`，事务提交后由调度器执行。响应中的 `task_id=task-<id>` 为本地查询标识，`platform_task_id` 为统一任务主键。
- `TaskRun.provider_task_id` 为真实上游异步任务 ID；`provider_name`、`provider_status` 和任务事件记录上游状态。同步图片/音频接口可能没有上游异步任务 ID。
- 视频提交后由服务端 poller 查询状态、保存结果和结算，浏览器只读取本地记录。旧视频记录仍兼容原 provider ID 查询，并由后台同步结果。
- 图片/音频执行完成后先持久化结果和用量，再由执行器完成任务与结算。恢复时复用已保存结果；视频恢复时复用已有上游 ID。同步生成在上游已完成、结果尚未落库时崩溃，仍受上游幂等能力限制。

启动迁移为既有任务回填 `queue_type`，新增上游信息列及队列查询索引。更新后需要在负责迁移的后端节点启用 `DATABASE_BOOTSTRAP_ENABLED` 并重启。连接共享库且关闭 bootstrap 的本地进程，应等待迁移节点完成后再使用新版本。

验证：`backend/tests/test_studio_generation.py` 使用独立 SQLite 数据库和模拟上游，覆盖三类生成、队列隔离、持久化、恢复复用、预扣结算、列表筛选与用户归属；`test_task_scheduler_dispatch.py` 覆盖领取公平性、并发竞争与取消；实际付费生成需在配置好的环境进行联调。
