# 数字资产市场分期开发说明

本文是数字资产市场的产品与开发边界。Word 版本（含第一期页面截图）见 [数字资产市场分期开发说明.docx](./数字资产市场分期开发说明.docx)。实现细节、配置和历史变更仍以 [MARKETPLACE.md](./MARKETPLACE.md) 为准；本文负责划分两期范围，避免把 Web 版权交易和 App 持续收益混成一次交付。

模块保持独立：数据表使用 `marketplace_` 前缀，接口使用 `/api/marketplace/*` 与 `/api/admin/marketplace/*`。只复用现有登录和管理员身份。不改原创作、生成、计费、任务调度、存储函数和漫剧表。`C:\code\ReelBay` 只作流程参考，不改其代码。

文件继续共用后台「系统设置 → 存储 OSS」里的同一个 Bucket，市场文件固定放在 `marketplace/`。原业务目录保持原样。市场对象保持私有，访问时签发短时链接。OSS 未配置时，上传和依赖文件的发布返回 `503`，错误码 `MARKETPLACE_STORAGE_UNAVAILABLE`，不回退到本地存储，也不返回 `/static` 地址。

## 分期

| | 第一期 | 第二期 |
|---|---|---|
| 终端 | 用户端 Web、管理后台 | App 先做持续收益；Web 只补作者配置、系列基础浏览和运营后台 |
| 业务 | 作品广场、招募广场、版权确认与客服交易 | 平台投放、在线解锁、短剧分集、收益记账和人工打款 |
| 钱怎么走 | 页面展示参考价，购买和接单都联系客服，线下签约、收款、交付 | 观众在线支付解锁单条或单集；平台与创作者按比例记账，管理员人工打款 |
| 播放 | 免费作品播完整时长水印；付费版权作品只播水印试看 | 未购买只播试看；已购买获得永久在线播放权益，每次播放重新鉴权 |

第一期可以上线并运营。第二期在第一期作品、权属和 OSS 链路上继续加，不回头改第一期的客服购买规则。

短剧和单视频一起出现在作品广场。平台投放、内容订单、永久权益、收益账本和人工打款仍属于第二期，待真实 OSS、易支付回调和 App 播放端验收。Web 不提供独立观众端付费播放站。

## 第一期：Web 作品广场、招募广场与版权交易

### 入口

用户端顶部只保留一个「数字资产市场」。进入后切换：

- 作品广场 `/marketplace`
- 招募广场 `/marketplace/recruits`
- 发布作品 `/marketplace/works/new`
- 发布招募 `/marketplace/recruits/new`
- 我的发布 `/marketplace/mine`

管理后台放在侧边栏「业务」分组下，名称是「数字资产平台运营」。日常导航是作品审核、招募审核、举报处理、客服配置、作品分类。媒体任务和操作记录收在默认折叠的「运行维护」里。

广场点进作品，看到的是买家页：视频、介绍、参考价、「联系客服购买」。作者的编辑、提交审核和上下架只从「我的发布 → 查看与管理」进入。招募同理：广场是需求帖和「联系客服接单」，管理页才有编辑、审核和关闭。

### 作品发布

一次发布只绑定一条视频和一个作者上传的封面。发布页不展示历史文件列表，重新上传即替换当前选择。

保存草稿只保存作品资料，不要求签署授权函或上传版权材料，也不生成试看。

收费在第一期只有两种：

- **免费公开**：价格为 0。审核通过并上架后，公众播放完整时长水印，不提供无水印原片。免费不代表可以任意商用。
- **联系客服购买版权**：填写参考价。参考价大于 0 时，公众只能看水印试看；参考价为 0 时按免费处理，播放完整时长水印。无水印原片不进入公开播放接口。

作品分类由管理员配置，发布页用下拉选择，广场用同一份配置做筛选。初始分类为短片、广告、动画、文旅、科普、其他。移除分类不改历史作品。

提交审核前必须补齐：

- 视频已上传；
- 封面已上传；
- 标题、简介、分类、拟授权用途及限制；
- 下面的版权材料。

按钮旁直接列出缺什么，避免只显示灰色按钮。

### 版权确认

用户只做一次确认，管理员只做一次审核。审核页里可以分成「内容检查」和「版权检查」两个区域，结果只有待审核、已通过、已驳回。

按来源分流：

- **PrintFilm 生成**：阅读并手写签署账号授权函，把当前视频关联到这份签署记录。不要求版权证书、截图或其他权属证明。授权函按账号与条款版本签署，作品仍逐件审核。
- **其他平台生成**：填写版权证书编号，上传证书截图或照片，勾选「版权纠纷与平台无关」。
- **没有版权材料**：联系客服线下协办。协办不创建登记案件，不自动通过审核，补齐材料后再提交作品。

不向用户展示基础核验、完整核验、私密核验、自行办理版权登记。修改版权材料后撤回已通过的审核和下架，防止旧审核结果批准新材料。

### 试看

作品在点击「提交审核」时才生成水印播放文件，不在上传或保存草稿时转码。

试看规则：

- 有标价的版权作品时长取 15 秒和原片时长 30% 中的较小值；免费和零元作品保留完整时长；
- 保留原分辨率和原帧率，使用高保真编码；
- 水印烧进画面，内容为 PRINTFILM、作者名字和「侵权必究」；
- 不生成封面，封面以用户上传为准；
- 生成成功后自动进入待审核，失败可重试；
- 试看未就绪时，公开接口不回退原片。

免费和零元作品生成完整时长水印，有标价的版权作品生成短试看。收费方式变化后先下架，生成对应水印并重新审核后才能再上架。已经保存出去的无水印原片无法收回。

媒体处理由市场 Worker 完成。它随后端自动启动、停止，异常退出后自动恢复，并发保持 1。它不接入原项目 AI 调度和计费。免费作品的完整时长转码也由它串行处理。

### 作品广场

广场以封面浏览为主：分类、搜索、价格区间、最新和价格排序。卡片展示封面、标题、作者和参考价；免费作品价格显示「免费」。

买家详情：

- 免费作品播放完整时长水印；
- 付费作品播放水印试看；
- 「联系客服购买」打开展示真实客服二维码、微信号和服务时间；
- 可复制作品编号、标题、参考价和链接；
- 弹窗说明：购买使用授权不等于取得版权。购买著作财产权须另行签订书面转让合同并办理手续，可能产生办理、登记或服务费用，参考价不包含这些费用，费用和承担方先与客服确认。

客服未配置时显示「客服暂不可用」，不用社区入群微信代替。

上传成功且云端预览可播放后，自动关掉本地预览，改显示云端文件。上传失败时保留本地预览。

### 招募广场

招募是需求展示和客服撮合，不接受站内投稿。

需求方填写标题、说明、分类、单条预算、数量、时长、画幅、用途、交付要求、授权意向、截止时间，最多 6 张参考图。管理员审核通过后公开展示。

创作者打开需求帖，登录后点「联系客服接单」。咨询不代表已接单或成交。不上传应征视频，不报价，不审片，不选稿。

关闭、到期、未审核或封禁的需求不再接受新咨询。作者从「我的发布」管理自己的需求。已有历史投稿只留在后台「运行维护」，不恢复投稿入口。

### 第一期验收

- 不配置 AI、支付和邮件，仍能完成上传、草稿、版权确认、一次审核、上架、广场浏览和客服咨询。
- OSS 未配置时上传被明确阻断。
- 广场点击作品不会进入作者管理页。
- 草稿保存不要求授权函或版权证明。
- PrintFilm 作品签署授权函后可以提交；其他平台作品缺证书编号、截图或勾选时不能提交。
- 付费作品公众只能拿到试看；免费作品播放完整时长水印，不返回原片。
- 招募详情没有投稿表单，新投稿接口保持关闭。
- 原项目登录、生成、计费和漫剧流程不受影响。

## 第二期：App 持续收益

第二期从 App 观众付费解锁开始。Web 第一期的客服版权购买继续保留，不改成自动交易。

### 收费类型

在免费公开、联系客服购买版权之外，增加 **平台投放收益**。三种类型互斥。

| 类型 | 观众看到什么 | 钱怎么结算 |
|---|---|---|
| 免费公开 | 完整时长水印 | 无订单 |
| 联系客服购买版权 | 水印试看，联系客服 | 线下签约收款，不产生平台订单 |
| 平台投放收益 | 未购买看试看；支付后永久在线播放 | 在线支付，按比例记账，人工打款 |

版权参考价和平台解锁价分开保存。平台投放必须填写大于 0 的解锁价。版权材料仍按第一期规则，在同一次审核里检查。

### 分成

后台先配置统一的创作者分成比例，平台比例由系统用万分比计算。未配置统一比例时，平台投放作品可以存草稿，不能提交审核。

单个作品或单个分集可以覆盖分成比例；留空则使用后台统一配置。订单支付成功时把当时的比例写进账本，之后修改配置不影响已入账订单。

### 短剧

单条短视频作品保持不变，不把历史作品改成剧集。短剧系列和单视频一起出现在作品广场，发布时在同一入口选择「短剧」：

```text
短剧系列
  └── 第 1 集
  └── 第 2 集
  └── 第 N 集
```

分集来源：

- 手动上传，每集一个视频、一个封面；
- 用户明确选择后，从自己的漫剧项目导入已经生成成片的分集。导入时复制到 `marketplace/`，保存项目和分集快照。之后原漫剧修改不影响市场内容，市场也不回写漫剧。

同一系列提交时收费类型保持一致。平台投放按集购买、按集定价、按集分成。购买一集只解锁这一集的当前发布版本。

系列提交时检查：至少一集、集数连续、每集视频和封面就绪、每集版权材料齐全、每集都有对应水印播放文件、投放集已有解锁价和可用分成配置。短剧卡片出现在作品广场，不单独开设短剧页。任意一集不通过，系列不能上架。

### 支付、权益和打款

不使用原 AI 充值钱包，不写入原 `orders` 表。支付通道复用现有易支付适配器里的支付宝和微信能力，订单、权益、账本使用市场自己的表。

观众流程：

1. App 请求解锁订单；
2. 跳转支付；
3. 回调校验签名和金额；
4. 同一笔回调重复到达只入账一次；
5. 写入永久观看权益；
6. 写入平台收入和创作者收入，两者之和等于实付金额。

同一用户重复购买同一发布版本时返回已有权益，不重复分账。本期不支持退款，支付成功后不自动撤销权益。

创作者在 App 或后续 Web 查看收益明细。管理员在后台把待结算标记为已打款，并记录金额、时间、渠道、外部流水号、操作人和备注。本期不做自动提现。

支付参数或回调地址未配置时返回 `MARKETPLACE_PAYMENT_UNAVAILABLE`，不伪造支付成功，不提前开放原片。

作品替换视频或变更授权后产生新的发布版本并重新审核。已购买的旧版本继续对应旧播放文件，不自动换成新版本。

### 播放

平台投放内容：

- 未购买只签发试看；
- 已购买签发短时有效的 HLS 播放清单和分片，不返回原片地址；
- 播放版本保留原分辨率，不强制压到 720p；
- 审核通过后再生成完整播放版本，就绪后才进入 App 内容流；
- 每次播放重新鉴权。

这只能降低直接下载，不能阻止录屏。试看水印和账号权益用于追踪，不承诺无法复制。

文件目录：

```text
marketplace/works/
marketplace/series/
marketplace/previews/
marketplace/hls/
marketplace/rights/
```

仍由同一个市场 Worker 处理试看和播放版本，不新增第二套进程，也不写入原项目任务表。

### App 与 Web 的分工

App 第一批接口：

- 平台内容流和分集详情；
- 当前用户是否已解锁；
- 试看或已购播放地址；
- 创建解锁订单和查询支付结果；
- 创作者收益明细。

本期不做独立的 Web 短视频播放站，也不向抖音等外部平台自动发布。Web 只保留作者配置解锁价、分成和管理员查看订单、权益、账本、打款。

### 第二期验收

- 未配置分成时，平台投放不能提交。
- 单集或单作品分成优先于后台默认值。
- 支付回调重复通知不会产生第二份权益或账本。
- 未支付用户拿不到完整播放地址。
- 已支付用户获得永久在线播放权益。
- 导入漫剧分集不修改原项目。
- 第一期免费作品、客服版权购买和招募接单保持可用。
- 原 AI 充值、计费和漫剧生成不受影响。

本地没有真实支付和公网回调时，只验收接口、签名校验和权限边界，不把真实支付记为通过。

## 参考项目

只借鉴状态和边界，不复制代码。AGPL 项目不能搬进本仓库。

- PeerTube：内容公开、审核和播放权限。
- MediaCMS：媒体资产和后台运营。
- Owncast：自托管播放状态，它偏直播，不直接当点播付费模型。
- Video.js、Shaka Player：第二期 App 或后续 Web 播放器，当前不引入依赖。
- FOSSBilling：订单、账本和人工财务处理。
- social-auto-upload：以后如果要分发到外部平台，再做独立适配器。

GitHub 上没有一个项目同时覆盖本平台的版权审核、客服版权交易、永久解锁和人工分账，所以两期都做在现有市场模块上，而不是替换原项目。
