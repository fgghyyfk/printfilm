## 2026-10-24 主导航与自由画布入口改版

**状态：已完成待部署，尚未线上发布。** 顶部横向主菜单改为左侧分组导航，创作入口与资源协作入口分开展示；窄屏通过导航抽屉访问。全屏分镜与自由画布编辑器继续使用独立布局。

| 位置 | 入口 |
|---|---|
| 创作 | 工作台 `/`、漫剧 `/drama`、自由画布 `/canvas`、AI 短视频 `/history`、小工具 `/tools` |
| 资源协作 | 资产 `/assets`、团队 `/teams`、定价 `/pricing` |
| 底部 | 帮助、GitHub、语言切换、账户 |

自由画布提升为一级入口，不再依赖漫剧列表中的二级入口。`/canvas` 展示画布项目，`/drama` 只展示剧本项目；两者复用现有项目列表、创建与管理能力，分别向 `GET /api/drama/projects` 传入 `workflow=canvas`、`workflow=script`，由服务端筛选。旧调用不传 `workflow` 时继续返回全部可访问项目，个人与团队的空间隔离、权限和付款规则沿用现有实现，现有项目编辑地址不变。

部署验收需覆盖两类列表分流、个人/团队空间切换、已有项目直达、桌面左栏及窄屏抽屉；全屏分镜/画布编辑器不应被全局侧栏挤占。对应清单为 [G-05 / G-06](./PLACEHOLDER_BACKLOG.md#2-全局--壳层)。

## 2026-10-24 项目卡片与新建流程统一

**状态：已完成待部署，尚未线上发布。** 个人漫剧、自由画布和团队项目采用共享项目卡片，以原团队卡片的白底圆角、封面叠字和状态胶囊为统一规范。

| 共享组件 | 入口与职责 |
|---|---|
| `frontend/src/components/projects/ProjectCard.tsx` | `ProjectCard` / `ProjectGrid`：统一封面、三行标题、状态、简介、可选进度、费用及底部信息；桌面三列、平板两列、手机单列 |
| `frontend/src/components/projects/ProjectCreateDialog.tsx` | 个人漫剧、自由画布、团队项目共用的新建弹窗；按空间和创作类型传入约束与提交方法 |
| `frontend/src/lib/projectCreateForm.ts` | 新建表单的共享校验，保持字段错误、提交数据和界面约束一致 |

列表取消占据首个位置的大尺寸「新建」占位卡，将主要新建按钮固定在项目区域标题右侧；资产库等次要操作降低视觉权重。空列表继续提供明确的新建入口。搜索、状态筛选和批量管理独立于卡片，避免误触。

卡片无封面时使用柔和抽象底图与横排标题；封面标题最多三行，简介最多两行。分集进度仅在取得真实完成数据时展示，个人列表不推算虚假的完成进度。费用、资产数量、更新时间和团队参与者继续使用原有真实数据。打开项目、菜单、复选框与删除操作分别使用独立控件，避免按钮嵌套；团队删除权限和历史账单保留规则不变。

新建弹窗统一项目名称、故事内容、计划集数、画面风格和补充简介的层级。画布使用名称与说明表单。漫剧故事至少 20 字；计划集数必须是 **1–120 的整数**，预设选择和自定义输入共用同一校验；无效字段显示就地提示并聚焦。个人与团队各自的字数限制通过组件参数保留。提交中阻止重复提交及意外关闭；失败保留输入供修改。

部署验收需覆盖三类项目卡片、长标题与缺失封面、筛选和搜索、重命名及删除、批量选择、个人/团队权限，以及新建弹窗的集数边界、提交失败恢复与窄屏布局。对应清单为 [G-07 / G-08](./PLACEHOLDER_BACKLOG.md#2-全局--壳层)。

## 2026-10-24 资产库媒体分类

资产页移除右上角「漫剧项目 / 科普历史 / 个人中心」快捷跳转，导航统一走侧栏。原有角色、场景、道具、音色之外，增加图片、视频、音频分类；媒体分类按实际媒体类型筛选，因此角色图片也能在「图片」中找到。

`GET /api/drama/library-assets` 提供独立的只读分页目录，聚合当前空间的 `DramaAsset` 和个人空间的 `ToolRun.urls` 正式交付结果。工具结果按每个 URL 单独编号，失败或取消任务中已有的交付保留，无输出任务不把预览图当成片。个人和团队范围严格隔离；「未关联项目」用于独立工具结果。目录记录使用来源命名空间 key，工具记录不能作为可编辑项目资产 ID 使用。

无项目素材支持详情、预览、音频试听和下载，不显示「打开项目」；关联项目的画布素材进入原画布。视频无图片封面时使用视频占位，不把视频地址请求为图片。旧项目资产接口及引用选择器的过滤语义保持兼容。本次无需数据库迁移，发布需重启后端以注册新路由，并验证个人/团队隔离、分类、搜索、分页及空态。科普镜头与成片、分镜视频中未建资产记录的媒体尚未聚合，独立上传参考文件不作为正式成品展示。

试听失败仅显示播放提示，资产列表继续可用。切换个人/团队空间或登录身份时，资产页重建当前目录状态，关闭旧详情、停止试听并取消旧请求，避免旧空间内容残留。

2026-10-26 本地验收：运行中的后端已加载新路由，未登录请求返回 401；使用已授权诊断项目的所属账号进行只读查询，全部资产、图片、视频、音频、未关联项目、单项目、项目名搜索及第二页均返回 200。检查分类匹配、跨页 key 不重复、无项目记录不产生项目链接、非法类型返回 422。前端 73 项及后端相关 19 项回归通过。此记录仅表示本地验收通过，线上发布仍需完成部署后的同类检查。

## 2026-10-26 移除开放 API

删除设置页 API Key 分区、密钥管理客户端及样式，旧 `?tab=api` 回落到账号信息。后端删除用户密钥路由、密钥服务、ORM/请求模型及 `/api/v1` 生图、生视频、Seedance 提交和查询路由；站内鉴权只接受登录 JWT，旧密钥及 `X-Api-Key` 不再提供站内访问能力。任务注册、报价/估价分支、管理端领域筛选和对外调用说明同步清理。

历史账单、用量与任务记录不删除、不重算；已取得上游任务 ID 的历史任务仍通过共用轮询与结算代码收尾，避免冻结资金悬挂。历史队列字段回填保留必要的数据兼容。旧 `user_api_keys` 表不再注册或访问，本次不执行删表；上游模型渠道密钥与站内生成继续使用。

发布需更新前端、管理端并重启后端全部实例，确认旧密钥管理和生成地址返回 404、旧密钥访问站内接口返回 401、登录 JWT 正常，再验证工具生成、计费和历史记录。只刷新前端不能停用仍在运行的旧后端。

本次源码验收：前端 79 项、后端相关 211 项测试通过，前端与管理端构建及静态检查通过（保留已有告警）。本地旧后端未开启热重载，自动审批拦截了进程重启，运行服务尚需重启验证；旧地址返回 401 仅表示未登录，不能作为路由删除成功的证据，重启后必须检查为 404。

## 视觉约定

- 主色石灰绿：`#B6FF00`（`--pf-lime`）
- 背景：`#F7F8FA`（`--pf-bg`）
- 卡片白底、圆角约 14px、轻阴影
- 项目卡片使用共享 `ProjectCard`，18px 圆角、封面叠字、状态胶囊；新建操作放在项目区标题右侧，不混入项目网格
- 左侧分组主导航：创作、资源协作；次要工具及账户放底部，窄屏使用抽屉
- 全屏分镜与画布编辑器保留独立布局，不嵌入全局侧栏
- 帮助等次要面板：右侧抽屉（`Modal variant=drawer`），避免居中大弹层挡工作台
