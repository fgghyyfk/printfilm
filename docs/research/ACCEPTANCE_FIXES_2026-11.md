## 执行和验收

- [x] **B1：取消残留。** 核对 `pipeline.py`、任务 handler/executor 和取消入口，按真实执行生命周期清理对应取消状态。不能在新任务入场时抹掉仍在途旧任务的取消；多个单镜任务不能互相清标记。验证运行中合成取消、排队取消后重试，以及旧任务退出前仍禁止新整片任务。
- [x] **B2：待核对结算出口。** 保留明确上游零成本证据，工具/API 失败路径与执行器采用一致口径；缺失 usage、默认 tokens=0、超时不是零成本。现有管理员任务详情增加核对后结算入口，只接受尚未结算的待核对任务，拒绝仍存活的本地执行，要求明确的最终费用确认及核对说明。管理员确认的是“未记录的缺失调用成本”，不是覆盖任务总成本；复用现有用户扣费等于成本的规则，已记录用量保持不变。零新增成本也须明确确认。任务锁、既有账本幂等门闩和结算同事务，保存操作人及核对记录；重复相同操作不重复扣退，冲突操作拒绝，已结算历史不得自动追扣。只结束本地处理、保留原任务号和媒体快照，不重新生成或声称已取消上游。管理员筛选、状态“待核对”和处理确认文案同步。真实双连接核对钱包和流水，覆盖权限、重复/冲突、已有费用和未知费用不自动退款。
- [x] **B3：漫剧同镜重复入队。** 在余额预检之前按现有锁序锁定分集并新读分镜及活跃任务，重新核验本次报价输入；价目与尾帧准备留锁外，使用现有 prepared estimate 接点。双连接同时请求同镜只能形成一笔任务承诺，后者返回中文冲突；任务终态后允许主动重生成。
- [x] **B4：站内导航保稿。** 将现有路由最小接入 DataRouter，以公开 useBlocker 覆盖真实 PUSH/REPLACE/POP 入口。两页共用一个导航保存边界，读取同步 dirty/saving 状态；等待现有串行 flush 保存最新 B 后放行，409/错误保页保稿。分集画布复用现有 createFragmentAutosave，移除被替代的 timer/saveInFlight 编排，并接 beforeunload。路由和保存器不随语言重建。覆盖真实任务抽屉 Link、浏览器返回、画布返回，而非不存在的编辑页 SiteNav。
- [x] **中 1：内置口播失效。** native audio 模式真实口播变化时清受影响视频/尾帧、保图，已有有效脚本同步新旁白；历史空脚本不凭空造画面。外部 TTS、image_text、avatar 的媒体语义保持，字幕/同值不误清视频。纠正原测试的 native 分支预期。
- [x] **中 2：隐私补音复用。** native 模式只失效改动镜头的备用音轨，外部整片配音维持全镜失效。现有当前镜头/旁白/voice 指纹文件可用时直接恢复 URL，不新增 TTS 或费用，也不虚构来源元数据。真实变化才生成新音轨。
- [x] **中 3：计划停服恢复。** scheduler 在取消业务任务前登记本次明确计划停机的任务，待其退出后清理；执行器恢复仍经过原费用、finalizing、用户取消及 provider 保护，仅不消耗恢复次数和阈值。不能依赖会被内层重新抛出丢失的 CancelledError 参数。普通异常取消和孤儿恢复继续计数。
- [x] **新库/升级库测试兼容。** NULL 旧数据用例在自身隔离事务中模拟旧列约束；不放松生产新表 NOT NULL，不全局修改测试库约束。
- [x] **本批代码统一复验。** 先补失败复现，使用新 PG/Redis、空付费凭据和 Python 外网拦截；测试集中运行，未逐项重复全量回归。新增边界或实际失败修正后仅补跑关联模块。前后台构建、Node 测试、lint 及 diff 检查通过，详见下方证据；规格/质量由只读审查者复核。
