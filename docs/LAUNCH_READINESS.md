# 独立运营上线清单

> 目标：把 PRINTFILM（kaikou.haituike.com）作为独立项目开放给第三方用户注册、付费使用，重点是「数字人口播」。
> 本文是 2026-10-30 对代码与线上环境的一次排查结果，按「阻塞上线 / 上线前应补 / 可后续」分级。每项修完在前面打勾，并在 `docs/releases/` 记一笔。

## 一、现状速览

| 项目 | 现状 |
|---|---|
| 线上地址 | https://kaikou.haituike.com（新加坡，Zenlayer 共享机 8 核 16G，同机 37 个容器） |
| 管理后台 | 不对公网开放，只能经 SSH 隧道访问 `127.0.0.1:18091` |
| AI 生成 | 线上 `ARK_MOCK=true`（假素材）；数字人素材服务已配 promptoll Key |
| 计费 | `BILLING_ENABLED=false`，数字人 GPU 单价 0 |
| 对口型 GPU | 1 张 RTX 3090（家里 Win10），经反向隧道接入；480p 约 3 分钟 GPU / 每秒视频，一天约 7 条一分钟视频 |
| 存储 | 本地磁盘，`OSS_ENABLED=false` |
| 备份 | kaikou 数据库**没有**定时备份 |

## 二、已经具备（不用返工）

- **项目越权**：项目相关接口都走 `_get_owned_project` 按 `user_id` 过滤（`backend/app/api/projects.py:148-156`），批量生产也先校验源项目归属。
- **易支付回调**：验签用 `compare_digest`、行锁防重复入账、金额校验（`backend/app/api/billing.py:407-451`）。
- **失败续跑**：失败可重试，已完成分段保留、只补缺的（`backend/app/services/kepu_avatar.py:130,139`，`kepu_avatar_batch.py:120-135`）；单段场景图/配音/视频可单独重做。
- **用户自助**：充值记录、扣费明细、月度用量（`frontend/src/components/billing/`），中英文，帮助页、价格页、用户协议与隐私政策页（`frontend/src/pages/LegalDocPage.tsx`）。

## 三、阻塞上线（P0）

### P0-1 注册登录防刷
- **问题**：注册不验证邮箱/手机、无验证码、不限频，注册即送 500 分（`backend/app/api/auth.py:39-69`，`backend/app/config.py:145`）；登录可被撞库（`auth.py:72-77`）。
- **方案**：注册加邮箱或短信验证码 + 图形验证码；登录/注册/发码按 IP 与账号限频；赠金改为验证后发放。
- **验收**：同一 IP 短时间批量注册被拦截；未验证账号拿不到赠金。

### P0-2 账号封禁与令牌作废
- **问题**：User 无 `is_active`（`backend/app/models.py:38-54`），`get_current_user` 只解析令牌（`backend/app/deps.py:27-36`）；JWT 7 天有效，改密后旧令牌仍可用。
- **方案**：加 `is_active` 与 `token_version`，JWT 带版本号；后台可封禁/解封；改密、重置密码、封禁时版本号 +1。
- **验收**：封禁后已登录会话立即 401；改密后旧令牌失效。

### P0-3 数字人全链路计费 ✅ 已完成（代码）
- **问题**：
  - 定妆照、单段场景重画在请求内同步改图，不建 TaskRun、不冻结、不记用量（`backend/app/api/project_avatar.py:79-142`，`kepu_avatar_look.py:116,186`），gpt-image-2 约 ¥1.8/张，可无限次调用。
  - AI 写稿 `avatar_ai.chat_json` 无用量记录（`kepu_avatar_look.py:69`）。
  - GPU 单价默认 0，为 0 时不记账（`config.py:86`，`kepu_avatar.py:288-290`）。
  - `avatar_auto` 预扣固定按 60 秒、不含场景图（`backend/app/services/billing/estimates.py:230-234`）；批量提交前不查余额（`kepu_avatar_batch.py:77-93`）。
- **方案**：改图/写稿/OpenAI 配音都写 `usage_events`；定妆照与场景重画按次预扣；按文稿字数估算时长预扣；批量先算总价、余额不足直接拒绝；后台设 GPU 单价；改图接口单用户限频。
- **验收**：开启计费后，一条数字人视频的每笔上游成本都在用户扣费明细中可见。
- **完成情况（2026-10-30）**：改图/写稿/OpenAI 配音写用量行；定妆照与场景重画改为请求内轻量任务预扣 + 限频（同时 1 张、每小时 30 张，429）；全自动出片按文稿字数估价；批量提交前整批校验余额，确认框显示预计费用。详见 `docs/BILLING.md`「数字人口播」。**上线时还需**：后台设置 GPU 单价 `avatar_price_fen_per_sec`、开启计费；需在有 PostgreSQL 的环境跑一次真实扣费联调。

### P0-4 任务队列公平 ✅ 已完成（代码）
- **问题**：全站与单用户并发默认都是 4（`config.py:100,102`）；`avatar_auto` 在进程里一直占槽位直到出片（1–3 小时，`services/tasks/handlers.py:184-187`），一个 50 条的批量能堵死全站所有任务。GPU 服务单一全局队列，不按用户轮转（`deploy/avatar-gpu/server/server.py:60,252`）。
- **方案**：数字人任务独立槽位池，或改为「提交 GPU 后进入 awaiting_poll 由 poller 轮询」，不再占执行槽位；GPU 侧按用户轮转出队，单用户排队上限（如 10 段）；批量分批放入队列。
- **验收**：用户 A 提交 50 条批量时，用户 B 的普通任务和数字人任务仍能按时开始。
- **完成情况（2026-10-30）**：新增 GPU 长任务槽位池（`services/tasks/gpu_pool.py`），`avatar_auto` 与数字人视频阶段不再占全站 Worker 槽位；默认全站 2、单用户 1，后台可调；分段逐段提交，各用户轮流进 GPU。GPU 服务侧仍是单队列，多 GPU 负载均衡留在 P2。

### P0-5 媒体私有化
- **问题**：`/static/generated/p{id}/` 公开挂载、免登录（`backend/app/main.py:79-85`），文件名可推（`final.mp4`、`avatar_face.jpg`、`avatar_portrait_{n}.jpg`），人脸照属于敏感个人信息。
- **方案**：用户上传与成片改为随机文件名 + 签名 URL（带过期时间）；开启 OSS 私有桶；公开分享另做显式「分享链接」。
- **验收**：不带签名访问他人项目媒体返回 403。

### P0-6 API Key 权限
- **问题**：`pf_` Key 在 `get_current_user` 里等同登录（`backend/app/deps.py:13-16`），管理员的 Key 拥有后台全权限（`deps.py:56`）。
- **方案**：Key 只允许访问 `/api/v1`；后台接口拒绝 Key；Key 增加作用域与单 Key 限频/额度。
- **验收**：用 Key 调 `/api/projects`、`/api/admin/*` 返回 403。

### P0-7 运维基础
- **问题**：kaikou 数据库无备份；线上 `ARK_MOCK=true`、计费关闭；`/docs` 公开；`SECRET_KEY` 有默认值 `dev-secret-change-me`（`config.py:21`）且启动不校验（线上已是 64 位随机值）。
- **方案**：每日 `pg_dump` + 媒体增量备份到异地，保留 14 天并演练恢复；生产关闭 `/docs`、`/redoc`、`/openapi.json`；生产环境检测到默认密钥直接拒绝启动；切换真实模型并开启计费。
- **验收**：能从昨天的备份恢复出一套可用环境；公网访问 `/docs` 返回 404。

### P0-8 合规
- **问题**：AI 标识只有画面右上角「AI 生成」小字（`backend/app/services/ffmpeg_compose.py:722-731`），无文件元数据隐式标识，音频无提示；上传人脸只有一行提示（`frontend/src/components/studio/AvatarSetupBlock.tsx:136`），无授权勾选与留证；照片与数字人文稿不审核；注册页无同意条款勾选（`frontend/src/pages/AuthPage.tsx`）。
- **方案**：成片写入元数据隐式标识（如 `comment`/`metadata` 带生成方、时间、内容编号），显式标识按《人工智能生成合成内容标识办法》要求放置；上传人脸必须勾选「本人或已获授权」并记录用户、时间、IP、照片哈希；照片过内容审核，文稿过敏感词；注册与充值前勾选同意用户协议。
- **验收**：每条成片可从文件元数据查到标识；每张人脸照有授权记录。

## 六、非代码事项（需尽早启动）

1. **产能**：1 张 3090 每天约 7 条一分钟视频。对外运营需要租云 GPU（多张 4090/A10 等）并做多机调度；家用机 + 反向隧道不适合作为生产依赖。
2. **支付**：易支付属于第三方聚合，正式运营建议以公司主体接入微信支付/支付宝官方。
3. **备案**：面向公众提供生成式 AI 服务，一般需要生成式人工智能服务备案与算法备案；服务器在境外，国内访问速度与合规都要评估。建议咨询专业人士。
4. **独立部署**：现在与多个项目共用一台机器，建议迁到独立服务器（至少独立数据库与备份）。
5. **协议文本**：用户协议、隐私政策需补充人脸/肖像授权、AI 生成内容、数据保存期限等条款。
